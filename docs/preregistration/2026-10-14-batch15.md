## Expectation, stated before the run (the card's)
Pooled alpha about -1 to +2% a year, tracking error 4-6%, alpha t under 1. Likely FAIL; most useful as a second
forward-test candidate if weakly correlated with the momentum replica.

## Store and inputs
`config/prereg_b9.yaml` -> `data/live/replay_b9.duckdb`; price-only bars. `mcap_pit` and as-traded close from
`data.fundamentals.share_issuance_features` with batch 9's unit-error guard (dropped when `mcap_pit` > 10,000 x the
63-session median dollar volume). Per filing, from `data.b5_fundamentals.event_values`, the latest filing usable on the
reference day (`avail_ts` on or before it):
- ROE = TTM net income / latest total equity (net income = TTM diluted EPS x cover-page shares, batch 5's proxy;
  computed as `roa` x `assets` / `equity`).
- Accruals = (TTM net income - TTM operating cash flow) / mean of latest and year-ago total assets (cash-flow form).
- Leverage = latest total assets / latest total equity.

## Rules
1. Reference days: last session of May and November. Orders at the open of the first session after the third Friday of
   June and December. First rebalance June 2017 (2017-06-19); before it, 100% SPY.
2. Universe on the reference day. Reading fixed here: the eligible names are those with an as-traded close >= $10, at
   least 273 sessions of bars, the guard above, equity > 0 and all three inputs finite; the universe is the 500
   largest of them by `mcap_pit`.
3. Q: each input z-scored across the universe (signed so high = good: ROE as is, accruals and leverage negated),
   winsorised at +/-3, the three averaged, the average z-scored again.
4. Holdings: 100 names; a holding stays while ranked within the top 120; new names enter only within the top 80
   (`b9_books.select`).
5. Weights: `mcap_pit` x s(Q) (1 + Q above zero, 1 / (1 - Q) at or below), each capped at 5% and at 3 x its cap weight
   in the universe, the excess spread pro rata; when the caps cannot hold 100%, the multiple is raised, never the 5%
   (batch 9's registered reading, `b9_books.caps_for`). Any unused weight in SPY. Weights drift between rebalances.
6. No stops; a delisted holding exits at its last close x the store's delisting multiplier.

## Windows and grading (docs/gates.md: Full-period test, Bill rate)
Three simulations: **A** 2017-01-01 .. 2024-10-04, **B** 2024-10-07 .. 2026-10-05, **pooled** 2017-01-01 .. 2026-10-05;
each starts with the latest book on or before its first session. PASS on either route: (1) in both A and B, haircut
Sharpe > 0, alpha against SPY > 0 and alpha t >= 2.394; or (2) the same in the pooled window with alpha above zero in
each of A and B. One trial (`prereg-b15`).
Descriptive, not criteria: tracking error against SPY per window; correlation of the book's daily excess return (over
SPY) with batch 9's replica's; SPHQ's price return where the store holds SPHQ for the whole window (it holds SPHQ from
2024-10-07 only, so window B; no new data fetched).
