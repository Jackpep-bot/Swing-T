## The rules
- Each card runs its cited code with one change: `DATA_START` = 2010-01-04 (the store's first session), passed as a
  parameter (plan step 7), so the first reference date is end-February 2011 and the first trade March 2011. Before
  that the weights books hold SPY.
- Replica and batch 16 keep the inert score tilt batch 23 found (fixing it would be a different book).
- Universe size: `mcap_pit` as the 2010 build extends it. A name with no `mcap_pit` before 2016 ranks by its latest
  `dei:EntityPublicFloat` with `avail_ts` on or before the reference date; the results give the count of fallback
  names at each rebalance. The 1,000x share-count guard (`MAX_MCAP_TO_DOLLAR_VOLUME`) stays as in batch 9.
- Batch 16 and batch 3 cards: the share of the 500 with a TTM gross profit and total assets available at each
  rebalance is reported; if under 60% at the first rebalance, window O starts at the first rebalance where it is at
  least 60%.
- Costs: `weights_book.simulate` with the per-symbol cost table (10 bp default) for weights cards; the replay's costs
  plus the per-stock spread top-up for the engine card, as in batch 3. Delisted names exit at their last close x the
  store's delisting multiplier.

## Confirmation rule (window O)
- Replica: **Confirmed** if alpha vs SPY > 0, alpha t >= 1.96 and haircut Sharpe > 0.
- Batch 16 replica: **Confirmed** if alpha > 0, alpha t >= 2.241 and haircut Sharpe > 0.
- Gross profitability: **Confirmed** if haircut Sharpe > 0, net R per trade > 0, alpha > 0 and alpha t >= 2.241.
- Otherwise **Consistent, not confirmed** if alpha > 0; **Not supported** if alpha <= 0.

A confirmed card still goes through docs/gates.md and the owner before any paper risk. A "not supported" replica is
reported in the weekly report as an edge that did not carry back.
