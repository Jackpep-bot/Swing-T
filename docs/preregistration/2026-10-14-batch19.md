# Pre-registration: batch 19 (large-cap earnings-surprise drift)

Committed 2026-10-14 **before** any simulation of this rule exists on real data. The module was written and tested on
synthetic data only. Nothing below may change after the first run except a harness-only amendment, written into this
file before results are read.

Card: `docs/proposals/swing-methods-2026-10/batch19/sp500_earnings_surprise_drift.md` (branch `claude/batch19-cards` @
1b24f63). Earnings-surprise family trial 2 (bar `alpha_t_critical(2)` = 2.241). Implemented by
`swing_engine/research/b19_books.py`; quarterly EPS from `data.b5_fundamentals.event_values` (new columns `eps_q`,
`eps_q_year_ago`, tested by hand: a fiscal Q4 is the annual figure minus the three quarters before it, NaN when any
piece is missing).

## Expectation, stated before the run (the card's)
Alpha about 0 to +2% a year, pooled alpha t under 1, correlation with the replica 0.4-0.6; likely FAIL.

## Rules
1. Reference days: last session of March, May, August, November from March 2017; orders at the next session's open
   (first 2017-04-03). Before it, SPY.
2. Universe: as-traded close >= $5 and batch 9's `mcap_pit` guard, then the 500 largest by `mcap_pit`.
3. Eligible: the latest 10-Q / 10-K with `avail_ts` on or before the reference day, usable within the last 100 sessions
   (its availability session is later than reference session - 100), with both this quarter's and the year-earlier
   quarter's diluted EPS.
4. Surprise = (EPS this quarter - EPS the same quarter a year earlier) / close on the reference day. Reading fixed here:
   EPS on today's split basis over the split-adjusted store close, which is the same ratio as as-traded EPS over the
   as-traded close.
5. Holdings: eligible holders stay while ranked within the top 150; new names from the top until 100
   (`b9_books.select`, no entry limit). Weights `mcap_pit` capped at 5% (`b18_cz.cap_weights`; fewer than 100: scaled,
   rest SPY); weights drift between rebalances. No stops; delisting at the last close x the store's multiplier.

## Windows and grading (docs/gates.md: Full-period test, Bill rate)
A 2017-01-01 .. 2024-10-04, B 2024-10-07 .. 2026-10-05, pooled 2017-01-01 .. 2026-10-05. PASS on either route: (1) in
both A and B, haircut Sharpe > 0, alpha against SPY > 0 and alpha t >= 2.241; or (2) the same in the pooled window with
alpha above zero in each of A and B. One trial (`prereg-b19`). Descriptive: tracking error; the bottom-100 book under
the same rules; monthly excess-of-SPY correlation with batch 9's replica.
