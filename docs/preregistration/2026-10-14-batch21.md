# Pre-registration: batch 21 (large caps without their worst earnings disappointments)

Committed 2026-10-14 **before** any simulation of this rule exists on real data. Nothing below may change after the
first run except a harness-only amendment, written into this file before results are read.

Card: `docs/proposals/swing-methods-2026-10/batch21/sp500_earnings_disappointment_exclusion.md` (branch
`claude/batch21-cards` @ 27fe665). **Chosen after batch 19's results** (its bottom-100 book lagged; its top book lost to
turnover): earnings-surprise family trial 3, bar `alpha_t_critical(3)` = 2.394. Implemented by
`swing_engine/research/b21_books.py`, which reuses batch 19's universe and signal unchanged
(`b19_books.build_universes`, factored out of batch 19's run with no change to it: batch 19's harness counts reproduce
exactly) and batch 13's exclusion rule (`b13_books.exclude`).

## Expectation, stated before the run (the card's)
About +0.7% a year before costs, tracking error about 2%, pooled alpha t about 0.5-1.5; likely FAIL on the bar.

## Rules
1. Signal, universe and dates: batch 19's (docs/preregistration/2026-10-14-batch19.md): reference days the last session
   of March, May, August, November from March 2017, orders at the next open (first 2017-04-03); the 500 largest by
   guarded `mcap_pit` with an as-traded close >= $5; surprise from the latest 10-Q / 10-K usable within 100 sessions.
2. Excluded: the 100 lowest surprises among eligible names, plus previously excluded names still within the lowest 130.
   Names with no eligible surprise stay in the book.
3. Weights: every remaining name at `mcap_pit`, each capped at 10% (excess pro rata), summing to 1; drift between
   rebalances. Fully invested; SPY before the first rebalance. No stops; delisting at the last close x multiplier.

## Windows and grading (docs/gates.md: Full-period test, Bill rate)
A 2017-01-01 .. 2024-10-04, B 2024-10-07 .. 2026-10-05, pooled 2017-01-01 .. 2026-10-05. PASS on either route: (1) in
both A and B, haircut Sharpe > 0, alpha against SPY > 0 and alpha t >= 2.394; or (2) the same in the pooled window with
alpha above zero in each of A and B. One trial (`prereg-b21`). Descriptive: tracking error, the average excluded share
of the universe's cap, the excluded names cap-weighted against SPY, and the same orders on the total-return store
(`config/prereg_b9_tr.yaml`).
