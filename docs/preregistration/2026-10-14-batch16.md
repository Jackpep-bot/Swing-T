## Expectation, stated before the run (the card's)
Pooled return about 16-19% a year, alpha +2 to +5%, pooled alpha t about 1.2-2.0; likely FAIL on 2.690. If alpha is
above zero in both halves, it is the second forward-test candidate.

## Rules
Every rule of batch 9's `sp500_momentum_index_replica` (docs/preregistration/2026-10-14-batch9.md) unchanged: the 500
largest by guarded `mcap_pit` with the history rule, reference days end of February / August, orders after the third
Friday of March / September, 100 names with the 80 / 120 buffer, weights `mcap_pit` x s(z) capped at 9% and 3 x cap
weight (multiple raised when infeasible), no stops, delisting rule. Only the score changes:
- m = the replica's momentum z (12-1 return over the daily volatility between, z-scored, winsorised at +/-3).
- g = gross profit / assets from the latest filing with `avail_ts` on or before the reference day
  (`data.b5_fundamentals.event_values`), z-scored across the universe and winsorised at +/-3; a name without a value
  gets g = 0 and stays in the universe.
- z = (m + g) / 2, z-scored across the universe (not winsorised again); it ranks the names and feeds s(z).
- SPY before the first rebalance (2017-03-20); the caps always hold 100%, so no unused weight arises.

## Windows and grading (docs/gates.md: Full-period test, Bill rate)
Three simulations: **A** 2017-01-01 .. 2024-10-04, **B** 2024-10-07 .. 2026-10-05, **pooled** 2017-01-01 .. 2026-10-05.
PASS on either route: (1) in both A and B, haircut Sharpe > 0, alpha against SPY > 0 and alpha t >= 2.690; or (2) the
same in the pooled window with alpha above zero in each of A and B. One trial (`prereg-b16`).
Descriptive, not criteria: tracking error against SPY; correlation of daily excess return with batch 9's replica's;
the monthly correlation, 2017-01 onward, of the French BIG HiPRIOR + BIG HiOP blend minus the market with this book
minus SPY (batch 14's files in data/research/french/).
