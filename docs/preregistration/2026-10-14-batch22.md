# Pre-registration: batch 22 (large-cap opportunistic insider purchases)

Committed 2026-10-14 **before** any simulation of this rule exists on real data. Nothing below may change after the
first run except a harness-only amendment, written into this file before results are read.

Card: `docs/proposals/swing-methods-2026-10/batch22/large_cap_opportunistic_insider_buys.md` (branch
`claude/batch22-cards` @ 4553580). Insider family trial 5, bar `alpha_t_critical(5)` = 2.576. Implemented by
`swing_engine/research/b22_books.py` on the store's `insider_trades` table (SEC Form 3/4/5 data sets from 2006,
`data.insiders`) and its CMP labels (`data.insiders.label_trades`).

## Expectation, stated before the run (the card's)
Satellite small (often 10-40 names), tracking error about 2-4%, alpha about 0 to +1.5% a year, pooled alpha t under 1;
likely FAIL.

## Readings fixed here
- **Start**: the store's Form 4 data begin in 2006, so every year from 2017 is classifiable; the book starts with the
  windows (first order 2017-02-01). The card's 2019 fallback does not apply.
- **Dating**: the data sets carry the filing date, not the acceptance time; an event counts from its filing date, and
  the book trades at the open after the month-end, so a filing on the reference day is public before the order.
- **Insider**: officer or director flag on the Form 4 (`is_officer` / `is_director`); 10%-only owners excluded.
  Event: code P, value (shares x price as reported) >= $50,000.
- **CMP labels**: per owner and calendar year, on all P and S trades filed before 1 January of that year: routine if
  one calendar month has a trade in each of the 3 prior years, opportunistic if every prior year has a trade but no
  month repeats, otherwise unclassified (ignored).
- **"Filed while in the 500 largest"**: the company is in the universe (guarded `mcap_pit` top 500, as-traded close
  >= $5) at the last month-end session on or before the filing date (universes are built at month-ends from
  December 2016).

## Rules
1. Reference days: every month's last session from January 2017; orders at the next open; SPY before.
2. Holdings: companies with at least one opportunistic event filed in the 63 sessions ending on the reference day; at
   most 50 (the largest total event value / `mcap_pit` on the reference day; a company without `mcap_pit` that day is
   dropped). 2% each, the rest SPY; reset monthly.
3. No stops; delisting at the last close x multiplier. Costs: `weights_book.simulate`.

## Windows and grading (docs/gates.md: Full-period test, Bill rate)
A 2017-01-01 .. 2024-10-04, B 2024-10-07 .. 2026-10-05, pooled 2017-01-01 .. 2026-10-05. PASS on either route: (1) in
both A and B, haircut Sharpe > 0, alpha against SPY > 0 and alpha t >= 2.576; or (2) the same in the pooled window with
alpha above zero in each of A and B. One trial (`prereg-b22`). Descriptive: names per month and satellite weight; the
satellite alone (equal weight); the routine-buy placebo book (same rules); the same orders on the total-return store.
