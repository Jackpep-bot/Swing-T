Agreed with the coordinator after batch 17: use the CZ data without picking on the test window. The card is a
three-step rule run on the Mac: (1) commit which predictors the store can build, (2) select those with
post-publication t >= 2 through 2016-12 on value-weighted long-short returns, commit the table, (3) build one
cap-weighted top-100 large-cap book from the selected signals and grade it on 2017-26 as usual.

Counted as one trial, because the selection is a fixed rule that never sees 2017+; bar raised one step for overlap
with profitability, issuance and accrual cards already tested.

## Rejected this sweep
- **Equal-weighted or small-cap version**: CZ's spreads are largest there, but our small-cap map found no edge net of
  costs in 870 cells.
- **Grading each selected predictor as its own card**: that would be several trials and a higher bar for each; the
  single-predictor books are reported beside the verdict, descriptive only.
- **Selecting on full post-publication history (through 2024)**: it overlaps the grading window, the problem this
  batch exists to avoid.
